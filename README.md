Personal developer portfolio hosted on **GitHub Pages** (`khudayqulov.github.io`), built with a zero-dependency single-file architecture (`index.html`) and interactive 3D visuals.

---

### Features

- **Interactive Terminal Intro:** Matrix rain canvas, automated CLI boot sequence (`whoami`, `cat stack.txt`, `./deploy.sh --prod`), and glitch reveal.
- **3D WebGL Environment:** Custom Three.js (`r128`) scene featuring 1,800 glowing sprite particles, a dual-layer wireframe TorusKnot with orbital rings, floating polyhedra, and a reactive cyber-wave floor grid.
- **3D Fibonacci Skill Sphere:** Interactive, inertia-driven rotating tag cloud of 20 backend and DevOps technologies.
- **Trilingual & Adaptive UI:** Instant **UZ / RU / EN** language switcher, automatic light/dark theme detection with manual toggle, and 3D tilt cards.
- **Zero-Dependency Single File:** Pure HTML5, CSS3, and Vanilla JavaScript with embedded Base64 portrait and no external build step.

---

### Core Backend Stack

- **Languages & Frameworks:** Python, FastAPI, SQLAlchemy, Pydantic, Alembic
- **Async & Integrations:** `asyncio`, `httpx`, `aiogram`, Telegram Bot API & Mini Apps, REST API, WebSockets
- **Databases & Caching:** PostgreSQL, Redis, SQLite
- **Infrastructure & Deployment:** Linux, Nginx, `systemd`, Docker, AWS EC2, Git
